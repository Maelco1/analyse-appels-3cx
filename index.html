Comment sont calculés les indicateurs

Un appel = un Call ID. 3CX écrit une ligne par étape (SVI « Call Script 992 », file d'attente, agent, parking, transfert). Les étapes d'un même appel sont regroupées avant tout calcul, et les filtres s'appliquent à l'appel entier.

Répondu : un poste a décroché. Abandon : l'appelant a raccroché sans être répondu, soit en file d'attente, soit au SVI (pendant le message d'accueil, avant d'arriver dans une file). Les deux comptent comme abandons.

Appel court : abandon en moins du seuil choisi (erreur de numéro, appel coupé). Il reste visible mais ne pèse pas dans le taux de décroché. Mettez le seuil à 0 pour tout compter.

Taux de décroché total = répondus ÷ (répondus + abandons en file + abandons au SVI, hors appels courts). Taux en file = répondus ÷ appelants arrivés en file : il mesure la réactivité des agents. Passage du SVI = appelants arrivés en file ÷ tous les appelants : il mesure la perte pendant le message d'accueil. Le total est le produit des deux. Attente = temps en file avant le décroché. Durée = temps de conversation avec les agents (hors attente et parking).

Exclus : fax (888), codes de service (*77*…), ligne « Totals » de l'export. Les heures sont celles écrites par 3CX, sans conversion de fuseau.

Taux de décroché heure par heure

Total : part des appelants répondus. En file : part des appelants arrivés en file qui ont été répondus. SVI : part des appelants qui ont passé le message d'accueil. Total = SVI × En file. Appels courts exclus.
